## 2. Project Description

This project implements a simplified version of the NetBSD `ls(1)` command in C.

The program is named **`myls`** and is developed according to the provided **NetBSD 10.1 `ls(1)` manual**.

The program supports:

- Listing files and directories
- Hidden file handling
- File sorting
- Long listing format
- Numeric owner/group IDs
- Recursive directory listing
- Inode information
- Filesystem block information
- Human-readable sizes
- File type classification
- Symbolic link information
- Modification, access, and change time
- Non-printable character handling

## 3. Usage

./myls [options] [file ...]
